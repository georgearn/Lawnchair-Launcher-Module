## 🌟 Module Features
- Updated systemless installation of Lawnchair Launcher via Magisk with the option to remove the clock from home screen and fixed date view in the At a glance widget.
- Supports Android versions 10 (Q) to 14 (QPR3).
- Quickswitch Integration: Replaces Recents Provider without extra configuration.
- Automatic updates via Magisk/KSU.
